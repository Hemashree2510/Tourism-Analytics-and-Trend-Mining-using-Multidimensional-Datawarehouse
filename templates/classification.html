Tourism Arrival Classification

Supervised Machine Learning: Decision Tree Classifier (CART Algorithm)
Supervised Learning

Classifies sovereign destinations into Low (<20M), Medium (20M–50M), and High (>50M) tourist arrival categories. The model uses the preceding year's actual tourist arrivals (2022 arrivals) as input features to predict the subsequent target arrival tier (2023 arrival category).

Academic Data Constraint Notice:

The evaluation uses only four test records out of 17 mutually complete records. Results are preliminary and may not generalize to a larger set of countries.

Academic Methodology & Workflow

Step 1: Dataset Loading

Load country names and arrival columns using Pandas.

Step 2: Category Definition

Derive Low (<20M), Medium (20-50M), High (>50M) thresholds.

Step 3: Missing Value Cleaning

Retain records having both 2022 and 2023 figures (17 countries).

Step 4: Feature Selection

Set X = 2022 Tourist Arrivals (Millions).

Step 5: Target Definition

Set y = 2023 Tourism Category (Categorical string).

Step 6: Train/Test Partition

80% training (13 records) and 20% testing (4 records), stratified.

Step 7: Decision Tree Fitting

Fit DecisionTreeClassifier with max_depth=3, random_state=42.

Step 8: Prediction

Predict categories for the 4 unseen test countries.

Step 9: Model Evaluation

Calculate accuracy (75%), confusion matrix, and precision/recall.
